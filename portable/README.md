# 📦 PORTABLE YOKLAMA SİSTEMİ

## ✅ SIFIR SORUN - GARANTİLİ ÇALIŞIR!

Build almaya gerek YOK! Direkt çalışır!

## 🚀 KULLANIM (3 ADIM)

### 1. Node.js Yüklü mü Kontrol Et

CMD'de:
```bash
node -v
```

Eğer versiyon görünürse (örn: v22.17.0) → Yüklü ✅
Eğer hata verirse → Yükle: https://nodejs.org/

### 2. BASLA.bat Dosyasını Çift Tıkla

```
BASLA.bat  ← ÇİFT TIKLA
```

**İLK KULLANIMDA:**
- Dependencies yükler (2-3 dakika, sadece bir kez)
- Sonra server başlar
- Tarayıcı açılır

**SONRAKI KULLANLAMLARDA:**
- Direkt başlar (3 saniye)
- Tarayıcı açılır

### 3. Kullan!

Tarayıcıda: `http://localhost:3000`

## 🆘 SORUN ÇIKARSA

### "node: command not found"

Node.js yükle: https://nodejs.org/
Bilgisayarı yeniden başlat

### "Port 3000 already in use"

Port kullanımda. Çözüm:
```bash
netstat -ano | findstr :3000
taskkill /PID [PID_NUMARASI] /F
```
